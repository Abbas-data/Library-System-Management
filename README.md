# 📚 Library System Management (SQL Project)

## 📌 Project Overview
The **Library System Management** project is a SQL-based database project designed to manage and analyze library operations efficiently. This project includes book records, member details, employees, branch information, issued books, and return status tracking.

The main objective of this project is to improve library management through structured databases and SQL queries.

---

## 🎯 Objectives
- Manage library book records
- Track issued and returned books
- Maintain member details
- Store employee and branch information
- Perform SQL-based data analysis

---

## 🛠️ Tools & Technologies Used
- **SQL**
- **PostgreSQL**
- **CSV Files**
- **Database Management**

---

## 📂 Dataset Information
This project includes the following datasets:

- **Books Data** – Information about books
- **Members Data** – Library member details
- **Employees Data** – Staff information
- **Branch Data** – Library branch records
- **Issued Status** – Books issued to members
- **Return Status** – Returned book records
